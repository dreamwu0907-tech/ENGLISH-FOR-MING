# ENGLISH-FOR-MING · V3

以手機瀏覽器優先的個人英文學習網站，學習路徑由國中基礎逐步提升至 TOEIC 800。

## V3 已確認規格
- 第一版先使用文字題庫；聽力功能保留於後續版本。
- 彈性學習，不限制每日使用次數或要求固定每日進度。
- 六個階段、72 個單元：國中基礎、高中基礎、中級英文、多益入門、多益進階、多益 800 衝刺。
- 每單元目標 15–20 分鐘，包含 4 個核心單字、單一文法重點、選擇題與填空題。
- 每題提供繁體中文句意；提交後提供正確答案與解釋。
- 錯誤觀念進入複習池；以同一觀念的不同題目連續答對 3 次才標記掌握。
- 儀表板分開顯示學習完成度、已上架題庫、答題正確率、已掌握觀念、待複習觀念及剩餘估算學習時間。
- 第一階段 12 個單元、72 題已上架；其餘 60 個單元列入路線圖，題庫會分批撰寫及校對。未上架的單元不會被誤算為可學習內容。
- 國中階段完成 9/12 單元（75%）時，首頁顯示下一階段題庫更新提醒；使用者回到原 ChatGPT 對話框提出「開始更新下一階段題庫」，再由維護流程建置高中基礎題庫。提醒僅作為人工啟動提示，不會自動修改 GitHub。
- 學習資料只存在目前瀏覽器的 localStorage。V3 使用獨立儲存鍵，不讀取 V2 舊紀錄。

## 技術
- React + TypeScript + Vite
- GitHub Pages + GitHub Actions
- 無付費 API；第一版文字題庫離線可用（首次載入仍需網站連線）。

## 本機啟動
```bash
npm install
npm run dev
```

## 部署
GitHub Actions 會在推送至 main 後執行 `npm run build` 並部署至 GitHub Pages。Repository 的 Settings > Pages 應設定為 GitHub Actions。
