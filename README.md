# ENGLISH-FOR-MING

以 iPhone Safari 為主要使用環境的個人英文學習網站；本專案目前不規劃電腦版操作。

## 第一版功能
- 單字、文法、閱讀混合測驗，每回合最多 20 題
- 可跳過題目，跳過視為答錯
- 交卷後逐題顯示正確答案與中文解析
- LocalStorage 保存答題歷史、熟悉度與複習排程
- 連續答對 5 次標記熟悉；答錯重新安排複習
- 使用瀏覽器 Web Speech API 播放題目、單字及閱讀文章
- PWA manifest 與基本 Service Worker 快取

## 本機啟動
```bash
npm install
npm run dev
```

## GitHub Pages
已加入 GitHub Actions workflow。到 Repository 的 Settings > Pages，將 Source 設為 GitHub Actions。推送至 main 後會自動建置部署。

## 注意事項
- 題庫目前是示範題，後續需擴充與校對。
- TOEIC 分數只作極粗略練習參考，並非正式估分；正式估分需要足量、經校準的聽力與閱讀題。
- LocalStorage 只保存在目前瀏覽器及裝置；清除網站資料可能遺失。跨裝置同步需後續加入帳號及雲端資料庫。
- iPhone Safari 的語音種類依 iOS 系統可用語音而異，請以實機測試為準；基本發音使用裝置內建語音，不需付費 API。

## 新版 15 分鐘課程規格（2026-11）
- 完整路徑規劃為 5 個階段、100 個單元；每階段 20 個單元，章節清單見 `src/data/courseRoadmap.ts`。
- 每個單元的標準流程：置頂單字 → 單字練習 → 文法與情境 → 綜合測驗 → 逐題詳解。
- 每單元規劃 5 個核心單字；填空題答案限定在本課已教單字範圍內。文法變化必須先教再考。
- 每單元正式測驗規劃 10 題，另有 10 題延伸練習；全課程規劃 1,000 題正式題及 1,000 題延伸題。
- 完成測驗後逐題顯示正確答案、中文句意、文法理由、錯誤原因及完整句子翻譯；錯題可重新作答。
- 15 分鐘是單元建議完成時間，不設每日使用上限。

> 注意：目前已加入 100 單元的課程路線圖；各單元完整的 5 個單字、正式題及延伸題仍需依課程順序逐課編寫與校對。路線圖的題數是完整課程規劃量，不代表 2,000 題已全部完成。
